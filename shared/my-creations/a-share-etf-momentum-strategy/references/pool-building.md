# 标的池构建方法

## 流程

1. **拉全量** — 东财clist API，1205只ETF，13页×0.3s间隔
2. **排除** — 货币/债券/商品/海外ETF
3. **行业匹配** — 按关键词将ETF分入对应主题（**每只ETF只归1个主题**，按主题顺序优先匹配）
4. **流动性排序** — 每主题内按成交额降序
5. **截取TOP2** — 每主题保留流动性前1~2只

## 关键词匹配规则

- 字符串包含匹配（`kw in name`）
- 按主题顺序逐一检查，**第一个命中即止**
- 宽基指数类关键词要精确，避免误抓行业ETF
- 排除类关键词放在匹配前

## 注意事项

### 常见坑
1. **关键词过宽** — "能源ETF"会匹配"新能源ETF华夏"，因为"新能源ETF"包含"能源ETF"
   - 解决：匹配时判断 if kw=='能源ETF' and '新能源' in name: continue
2. **主题间重叠** — "储能电池ETF"同时含"储能"和"电池"
   - 解决：只归入第一个匹配的主题（有序字典），储能排在电池前
3. **恒生/北证类** — A股场内基本没有对应ETF，匹配不到直接跳过
4. **流动性不足** — 有些主题TOP2成交额<1亿，回测时注意滑点

### 去重
- ETF代码是唯一标识，池中不应出现重复代码
- 每个ETF只归入1个主题后，自然解决去重

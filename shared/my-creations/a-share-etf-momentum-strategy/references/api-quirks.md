# 东财API字段格式

## K线数据

**东财** (push2his.eastmoney.com):
```
日期,开盘,收盘,最高,最低,成交量
```
示例: `2026-04-30,1.316,1.315,1.328,1.302,8818984`

**腾讯** (web.ifzq.gtimg.cn):
```
[日期,收盘,开盘,最高,最低,成交量]
```
示例: `['2026-04-30', '1.315', '1.316', '1.328', '1.302', '8818984']`

> ⚠️ 两者字段**顺序不同**。东财第2位是开盘，腾讯第2位是收盘。数值本身一致。

## 封禁与可靠性

### push2his 封禁规律（重要！）
- **push2his** 会在连续拉取约200只ETF的K线后触发IP级封禁
- 错误特征：`Remote end closed connection without response`
- 2026-05-06实测：拉取68只正常，次日拉取1205只时前200只全部失败
- **clist API不受影响**，封禁只针对push2his这个域名
- 恢复时间不固定（几小时到几天）
- **解决方案**：批量拉K线时直接用腾讯API，腾讯从未被封过

### 推荐数据获取策略
| 场景 | 推荐API | 原因 |
|:---|:---|:---|
| ETF列表+实时排行 | 东财clist | 稳定，支持排序和分页 |
| 盘中查询单只行情 | 腾讯qt.gtimg.cn | 稳定，批量查询（50只/次） |
| 批量拉历史K线 | 腾讯kline | 1205只连续拉从未被封 |
| 少量（<50只）K线 | 东财push2his | 可用但别贪多 |

`push2.eastmoney.com/api/qt/clist/get`

关键字段：
| 字段 | 含义 | 转换 |
|:---|:---|:---|
| f2 | 最新价 | 单位：分，除以1000得元 |
| f3 | 涨跌幅 | 单位：基点，除以100得% |
| f5 | 成交量(手) | 直接使用 |
| f6 | 成交额(元) | 直接使用 |
| f12 | 代码 | - |
| f14 | 名称 | - |

> ❌ f62 是主力净流入，不是成交额。不要用。

## 翻页限制

- clist每页最多100条，1205只ETF需13页
- 页面键名是字符串数字（"0","1","2"...），不同页面会重复，合并时需用f12(代码)作key

## 防封禁

- 每次调用间隔 **≥0.3秒**
- 必须设置 `User-Agent: Mozilla/5.0`
- curl不加UA可能返回 `rc=102`（PHP urllib默认OK）
